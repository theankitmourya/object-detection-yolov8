
# Object Detection & People Counter using YOLOv8

A computer vision project for real-time object detection and people counting using YOLOv8 and OpenCV.

## Features
- Real-time object detection
- People counting
- Video input support
- SORT tracking
- YOLOv8 integration

## Technologies
- Python
- OpenCV
- YOLOv8
- PyTorch
- NumPy

## Project Structure

object-detection-yolo/
├── src/
├── assets/
├── samples/
├── weights/
├── requirements.txt
└── README.md

## Setup

1. Install dependencies

pip install -r requirements.txt

2. Download YOLO weights

https://github.com/ultralytics/assets/releases

Place yolov8l.pt inside:

weights/

3. Run

python src/main.py
